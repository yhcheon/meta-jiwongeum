## Tech Stack
- Next.js 14 App Router + TypeScript + Tailwind (#2563EB / #0F172A / #DC2626)
- Supabase (Postgres + Auth)
- Crawler: Playwright + Scrapy (bizinfo.go.kr 매일 01:00)
